# Memory Bank Database

This source package was generated by `mb init` and contains:
- Parser scripts to build a SQLite database from your markdown Memory Bank
- A small web app (Viewer + Editor) to browse/manage the database

## Quick Start

From the repository root:

1) Install dependencies

pnpm --dir code/memory-bank/database install

2) Run all parsers (build/rebuild the DB)

bash code/memory-bank/database/run-all.sh

This generates/updates the runtime database under
`memory-bank/database/memory_bank.db` in the repository root.

3) Start the viewer/editor

pnpm --dir code/memory-bank/database start

Then open:
http://localhost:3000

## Notes

- `run-all.sh` runs `pnpm install`, `pnpm approve-builds`, and all parser scripts.
- The Viewer includes an Editor tab for DB selection/creation and importing `edit_history.md` into a chosen DB.
- Markdown source files remain in the repository-root `memory-bank/` folder.
