# Hamiltonian-study pilot outputs

Generated by `code/python/hamiltonian_studies.py` from the repository root.
The saved run covers $K=2,3,4$, four sites, exact total-spin singlets, the
complete graph and periodic ring, and $g=0$.

- `summary.json`: model conventions, dimensions, controls, and numeric versions.
- `energy_levels.csv`: every eigenvalue in each graph and interaction control.
- `spectra.csv`: ground energy, gap, volume, and commutator summaries.
- `thermodynamics.csv`: Gibbs observables for the saved inverse-temperature grid.
- `active_site_probabilities.csv`: $P(N)$ and conditional volume by active-site count.
- `kinematic_active_site_counts.csv`: exact infinite-temperature dimensions and $P(N)$.
- `ground_state_correlations.csv`: pairwise occupation, spin, and bond-energy means in the zero-temperature Gibbs state.
- `ground_state_reduced_state.csv`: site-0 reduced entropy and purity for the zero-temperature ground-state mixture.
- `volume_distributions.csv`: probabilities of each positive-RS volume outcome.
- `commutator_edge_triple_terms.csv`: Frobenius and maximum-entry norms by hopping edge and volume triple.
- `k4_thermal_volume_scan.csv`: dense $K=4$ temperature scan, including $P(V=0)$ and the zero-temperature limit.
- `k4_energy_resolved_volume.csv`: volume means and zero-volume weights grouped by energy eigenspace.
- `operators_k*_*.npz`: magnetic occupations, singlet basis transforms, onsite, hopping and spin-correlation operators, triple volumes, volume sum, and the $U/t=5$ Hamiltonian.

This run used the `qc-diff` Conda environment: Python 3.10.19, NumPy 1.24.3,
SciPy 1.15.3, SymPy 1.14.0, and Matplotlib 3.10.8. The driver generated five
figures in both PDF and PNG formats:

- `ground_energy_vs_repulsion.pdf` and `ground_energy_vs_repulsion.png`
- `ground_energy_graph_difference.pdf` and `ground_energy_graph_difference.png`
- `thermal_volume_u5.pdf` and `thermal_volume_u5.png`
- `k4_thermal_volume_scan.pdf` and `k4_thermal_volume_scan.png`
- `k4_low_energy_volume_spectrum.pdf` and `k4_low_energy_volume_spectrum.png`

See [the study note](../../notes/hamiltonian-studies.md) for conventions,
results, and scope limits.
