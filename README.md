# LQG Coherent States & Grassmannian Scattering
Based on arXiv:2208.10632 — Vaid & Suresh, EPJC 2022

Project source is grouped under [`code/`](code/README.md): Python and Rust
calculations, the dashboard, Memory Bank tooling, shell workflows, and LaTeX
manuscript sources. Compiled paper PDFs remain in `paper/`. Run research
scripts from the repository root; their task records give the command for each
calculation. Research notes and experiment records are in
[`notes/`](notes/README.md), calculation outputs are collected in
[`results/`](results/README.md), and project figures are in `figures/`.
