# Fock Space Construction

*Last Updated: 2026-10-02 12:22:16 IST*

## Overview

The Fock space for LQG intertwiners is constructed using the Schwinger boson formalism, which maps SU(2) representation theory to harmonic oscillator algebra.

## Schwinger Boson Formalism

Each angular momentum $j$ is represented by a pair of harmonic oscillators $(a, b)$:
- $J_+ = a^\dagger b$
- $J_- = b^\dagger a$
- $J_z = \frac{1}{2}(a^\dagger a - b^\dagger b)$

The total spin is $j = \frac{1}{2}(n_a + n_b)$ where $n_a, n_b$ are occupation numbers.

The normalized Schwinger occupation state is already an angular-momentum basis state:

$$|n_a,n_b\rangle=\frac{(a^\dagger)^{n_a}(b^\dagger)^{n_b}}{\sqrt{n_a!n_b!}}|0\rangle=|j,m\rangle,$$

with $j=(n_a+n_b)/2$ and $m=(n_a-n_b)/2$. This is a relabeling by the
eigenvalues of $J^2$ and $J_z$, not a transformation that mixes states.

## Singlet-pair creator

For two legs, define

$$F^\dagger_{12}=a^\dagger_1b^\dagger_2-a^\dagger_2b^\dagger_1.$$

It is an SU(2)-invariant pair creator. Acting once on the vacuum gives

$$F^\dagger_{12}|0\rangle=|\tfrac12,\tfrac12\rangle_1|\tfrac12,-\tfrac12\rangle_2-|\tfrac12,-\tfrac12\rangle_1|\tfrac12,\tfrac12\rangle_2,$$

which is an unnormalized two-spin singlet (norm $\sqrt2$). More generally,
$(F^\dagger_{12})^J|0\rangle$ has spin $j_1=j_2=J/2$ on the two legs and
total SU(2) spin zero; its norm is $\sqrt{J!(J+1)!}$ in this oscillator
convention.

For $J=2$,

$$
(F^\dagger_{12})^2|0\rangle=2\left(
|1,1\rangle_1|1,-1\rangle_2-|1,0\rangle_1|1,0\rangle_2+|1,-1\rangle_1|1,1\rangle_2
\right).
$$

Each leg now carries local spin one, while the full two-leg combination remains
a total singlet. An individual product term has $M=0$ but is not itself a
definite total-spin state. The full normalized combination is the parenthesized
sum divided by $\sqrt3$.

## Relation to coherent states and RVB

The Freidel–Livine fixed-area U(N) states form a Perelomov coherent-state
family: the represented U(N) action generated by the bilinears
$E_{ij}=a_i^\dagger a_j+b_i^\dagger b_j$ acts on a highest-weight
intertwiner built from $(F^\dagger_{12})^J|0\rangle$. This is distinct from
the specific Freidel–Speziale state targeted by the project's open T1a/T3c
positive-volume validation; results for one construction do not complete the
other's validation.

The singlet-pair action is RVB-like because $F^\dagger_{ij}$ creates a bond
singlet and powers or superpositions distribute such bonds among legs. It is
not a standard lattice dimer-covering RVB state: the bosonic symmetrization and
intertwiner constraints differ.

## U(N) Decomposition

For an n-valent intertwiner with total spin $J$, the Fock space decomposes under U(N) as:
$$\mathcal{H}_J = \bigoplus_{\{k_i\}} \mathcal{H}_{\{k_i\}}$$

where $\{k_i\}$ are occupation numbers satisfying $\sum_i k_i = 2J$.

## Basis Enumeration

The basis states are labeled by occupation numbers $(k_1, k_2, ..., k_n)$ with:
- Constraint: $\sum_i k_i = 2J$
- Dimension: $\binom{2J + n - 1}{n - 1}$

## Dimension Growth

| n | dim(Fock) for J=1 | Notes |
|---|-------------------|-------|
| 4 | ~10 | Python manageable |
| 5 | ~35 | Python manageable |
| 6 | ~84 | Python slow |
| 7 | ~165 | Python impractical |
| 8 | ~286 | Requires Rust |

## Implementation

### Python (`coherent_states.py`)
- Direct NumPy array construction
- Explicit loop over occupation numbers
- Suitable for n=4 only

### Rust (`rust/src/fock.rs`)
- `sprs::CsMat` sparse matrix representation
- `rayon` parallel basis enumeration
- Support for n up to 8+

## Key Operations

| Operation | Formula | Implementation |
|-----------|---------|----------------|
| J_+ \|k⟩ | $\sqrt{(k+1)(2j-k)} \|k+1⟩$ | Sparse shift matrix |
| J_- \|k⟩ | $\sqrt{k(2j-k+1)} \|k-1⟩$ | Sparse shift matrix |
| J_z \|k⟩ | $(j-k) \|k⟩$ | Diagonal matrix |
