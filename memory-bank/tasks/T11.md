## Description

Implement the proposed single-copy lattice-Hamiltonian program on exact fixed-area SU(2)-singlet spaces. Begin with the four-site comparison between the complete graph and periodic ring at $K=2,3,4$, with empty sites allowed and $g=0$. Keep connected triples in the physical-volume sum and retain edge–triple contributions in the Hamiltonian–volume commutator.

## Scope limits

The first pilot has only four available sites. Both four-site graphs induce connected subgraphs on every three-site subset, so they use the same four volume terms; the graph comparison changes the hopping terms. The calculated positive RS operator is not physically calibrated, and the pilot does not establish a thermodynamic phase, a larger-graph cancellation rule, or a graph-reordering amplitude. Strict one-boson-per-site dynamics are not generated by ordinary hopping alone.
